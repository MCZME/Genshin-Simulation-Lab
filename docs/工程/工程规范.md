# 工程规范

本目录保存项目开发、测试、迁移和质量控制相关文档。

## 当前质量工具

- `pytest`：测试主框架。
- `pytest-cov`：覆盖率统计。
- `ruff`：代码检查、导入排序和格式化。
- `pyright`：静态类型检查。

常用命令：

```powershell
uv run pytest
uv run pytest --cov=genshin_sim
uv run ruff check
uv run ruff format
uv run pyright
```

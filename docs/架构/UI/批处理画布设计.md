# 批处理工作流画布设计

> 状态：已确认（2026-08-15）
> 本文定义 UI 工作流画布的产品形态、区域模型、数据模型、节点与连线语义、模拟桥节点、分析区域与保存重跑语义。节点编辑器细节、交互原型与持久化契约在实现阶段另行细化。
> 最后更新：2026-08-17；2026-08-17 确认枚举/区间进入 MVP；同日确认图语义归前端，后端只接受已展开成员。

## 1. 产品定位

- 新项目应用端定位为分析工具，核心能力围绕仿真结果、战斗复盘、参数扫描和结果对比逐步展开。
- UI 的一等公民是“批”（一组模拟输入）；单次模拟输入是批的特例。
- 采用单一无限画布承载完整链路：配置 → 模拟 → 分析；画布即工作流，工作流可保存、复用与重跑。
- 产品始终以画布为中心，不设置脱离工作流上下文的独立运行历史页面；历史结果通过分析区域的数据提供节点进入当前工作流。
- 工作流选择、新建、重命名和管理属于顶部栏，不占用画布节点工具区；顶部栏同时承担“全部运行”入口。

### 1.1 用户认知边界

- 界面假定用户熟悉原神中的角色、武器、圣遗物、队伍、目标和战斗过程，不假定用户理解项目代码、数据契约或存储结构。
- 常规界面使用显示名称和任务语义，不暴露或要求用户输入 `asset_key`、`handler_key`、JSON 路径、`session_id` 等内部标识。
- 内部标识只允许出现在明确的排障或开发入口中，不能成为常规配置、运行和分析流程的必需知识。

## 2. 整体模型

- 画布上创建“区域”，区域是画布对象：创建时选择类型（配置区域/分析区域）与名称，可移动、缩放；第一版不支持折叠；允许存在多个同类型区域。
- 节点放入区域获得归属；游离节点可以作为草稿存在，但不能连接或参与运行。
- 模拟节点是跨区域桥节点，不归属任何区域；输入侧只连接配置区域的边界输出，输出侧只连接分析区域的边界输入。
- 数据语言随区域切换：配置区域流经片段数据与输入文档；桥节点把输入集合转换为会话集合；分析区域流经会话数据与派生结果。
- 工作流定义保存于 `<data_dir>/workflows/`，一个 JSON 文件一个工作流。

## 3. 数据模型

### 3.1 根数据与片段数据

- 根数据：携带根身份的完整 JSON 文档，自根节点出发。
- 片段数据：节点直接产生、不携带根的修改内容。
- 根数据之间不可合并；片段数据之间可以合并（深合并），合并结果仍为片段数据。
- 片段数据遇到根数据时，将整条片段链按顺序应用到根文档，产出新的根数据。

### 3.2 覆盖规则

- 覆盖只发生在同一叶子字段存在多个写入者时。
- 覆盖被允许，但画布必须显示警告：被覆盖节点提示“将被节点 X 覆盖，最终不生效”，覆盖节点提示覆盖了哪些字段。
- 生效顺序由连线/端口顺序决定，后生效者覆盖先生效者。
- 覆盖不阻止运行；配置区域的边界输出始终展示应用后的最终文档、成员数量和校验状态，供用户核对。

### 3.3 会话数据

- 模拟节点输出一组 `session_id`（会话数据），是分析区域的数据起点。
- 分析区域的数据流默认按成员展开：查询、指标节点对一组会话自动逐个处理；聚合节点把展开结果收拢。

## 4. 区域模型

- 区域类型：配置区域、分析区域。
- 区域是强规则边界：画布对象面板按区域类型提供；连线必须遵守“配置区域内 ↔ 模拟节点 ↔ 分析区域内”的阶段顺序；配置节点不得直接连接分析节点。
- 每个配置区域固定拥有一个边界输出，代表该区域形成的一组完整模拟输入；区域内参与输出的节点必须先汇入该边界，不能直接连接区域外对象。
- 每个分析区域固定拥有一个边界输入，代表从模拟桥接收的一组模拟结果；区域外对象不能越过边界直接连接分析节点，区域内节点从边界输入取得外部结果。
- 分析区域的边界输入可以不连接；此时可由区域内的数据提供节点选择历史结果。边界输入与内部数据提供节点是两个明确数据源，不互相替代或隐式合并。
- 区域边界端口属于区域，不是可移动节点。区域移动或调整尺寸时，外部连线只跟随边界端口，不依赖内部节点位置。
- 多个同类型区域允许，例如两个配置区域各生成一批输入，都汇入同一模拟节点。
- 第一版区域不开放嵌套。
- 区域通过画布对象面板中的区域项拖入画布创建，可重命名、调整大小；创建后区域头部提供区域运行入口。
- 画布对象面板提供“全部 / 配置 / 分析”显式筛选。点击配置或分析区域、点击区域内节点时切换到对应类型；点击模拟桥节点或画布空白处保持当前筛选。鼠标移动、悬停和拖拽现有对象不得切换画布对象面板内容。
- 画布对象面板分别记住最近明确选择的配置区域和分析区域，作为点击创建同类节点时的添加目标；面板显示当前添加目标。没有兼容区域时，点击创建的节点成为游离草稿。从画布对象面板拖入画布时，以实际落点决定归属，不在拖拽过程中切换面板内容。
- 节点拖入区域即归属，拖到空白处成为游离草稿节点。
- 工作空间采用有边界的弹性布局：工具区可以收起，画布随窗口与工具区伸缩；第一版不支持任意停靠、插件面板、用户自定义工作区和移动端布局。
- 第一版面向桌面鼠标与键盘，最低内容视口为 `1280 × 720`。
- 左侧工具区采用“常驻窄工具轨 + 按需展开面板”：工具轨提供节点和问题入口，两者共享一个展开面板；面板收起后工具轨仍保持可用。工具内容只由用户明确点击切换，不随鼠标移动或悬停变化。第一版不设置“大纲”工具。

## 5. 配置区域

### 5.1 节点清单

| 节点类型 | 职责 | 默认目标路径 | 参数 |
| --- | --- | --- | --- |
| 根节点 | 提供空 `{}` 或加载输入文件 | 无 | 文件路径（可选） |
| 元信息 | 写 `meta` | `meta` | 无 |
| 角色 | 写队伍槽位角色 | `team[i].character` | 槽位 i |
| 武器 | 写队伍槽位武器 | `team[i].weapon` | 槽位 i |
| 圣遗物 | 写队伍槽位圣遗物 | `team[i].artifacts` | 槽位 i |
| 目标 | 写场景目标 | `scene.targets[i]` | 目标索引 i |
| 按键轨迹 | 写按键输入轨迹 | `input_trace` | 无 |
| 运行选项 | 写运行控制项 | `run_options` | 无 |
| 枚举 | 对目标路径输出一组显式值 | 由用户指定 | 路径、取值列表、标签 |
| 区间 | 对目标路径输出数值序列 | 由用户指定 | 路径、起点、终点、步长、标签 |

### 5.2 通用属性

- 节点可以声明多个具有稳定 `port_id` 的独立输入、输出端口；常见形态仍为单输入、单输出。不同端口的连线和数据彼此独立，不能把“一个端口输出一组值”当作“多个独立输出端口”。
- 端口基数分为单值输出和组输出：单值端口每条连线携带一个值或片段；组端口输出有序成员组并触发下游展开。多个组输出的组合规则见 5.6。
- 节点可以为组成员提供投影端口。投影端口是独立的单值端口，连接后只输出对应成员；组主端口仍输出完整成员组。
- 显式枚举的每个成员拥有稳定 `item_id`，成员投影端口绑定 `item_id` 而非数组下标；调整枚举顺序不得改变已有连线指向。
- 组主端口和成员投影端口可以分别连接。多路独立输出重新汇入时不得静默恢复成组、拼接或叉乘；具体汇入操作必须由下游端口或显式节点声明，并在进入实现前写入工作流契约。
- 目标路径：节点类型声明默认路径；路径在画布上可见可改；队伍槽位、目标索引等作为节点参数。

### 5.3 配置区域输出

- 配置区域固定提供一个边界输出，负责数量确认、校验与最终文档预览，并向模拟桥输出一组完整输入文档。
- 区域内没有有效数据汇入时，边界输出显示为空并阻止运行；区域名称同时作为该输入流程的用户可识别名称。
- 边界输出不执行模拟，提交运行仍由模拟节点承担。

### 5.4 暂不实现

- 玩家节点：第一版使用默认位置/朝向。
- 规则节点：`rules` 第一版为空结构。
- 合并节点：片段合并由多输入节点隐式完成。
- 资产筛选：后续版本支持。

### 5.6 变体展开规则（2026-08-17 确认）

- 多个组输出相遇时按目标路径区分：目标路径不同则叉乘组合；目标路径相同则不叉乘，按[覆盖规则](#32-覆盖规则)处理并显示覆盖警告。
- 区间序列从起点开始，下一步值 `≤ 终点` 则继续生成（终点可被包含）；小数步长使用 `Decimal` 计算，避免浮点累积误差。
- 批次成员数量上限为 200；超过上限时配置区域边界输出直接报校验错误，阻止运行，并展示最终成员数量供预览。
- 每个成员拥有稳定 `item_id` 与确定展开顺序；调整枚举顺序或区间参数后，已有连线按 `item_id` 保持指向。
- 变体展开的输入输出模型与校验规则见[批量配置变体契约](../../契约/批量配置变体契约.md)。

### 5.5 配置区域编辑器约定

- 节点即编辑器：所有编辑都在画布内、节点内部直接展开，不跳转侧栏或独立页面。
- 节点整体不折叠，以保留画布上的所见即所得关系；节点内部的次要分组可以折叠，折叠后保留内容与状态摘要。
- 资产选择器：节点内显示当前资产的名称与图像，点击展开可搜索列表；不可运行的资产使用面向用户的状态说明，不显示内部绑定标识。
- 路径：节点类型维护自身片段形状与默认挂载点，不读取 SimulationInput schema；路径修改只做语法级检查，结构校验在配置区域输出完成。
- 枚举节点：值类型由用户声明（资产/数值/文本/JSON 片段），每组取值使用对应编辑器。节点默认显示完整组主端口；用户可以展开成员端口并把单个枚举值连接到独立分支。成员端口折叠后，已有连线仍保持并显示成员标签。
- 按键轨迹节点：轨道 + 滑块图形编辑。横轴为时间（帧与秒），纵轴为按键轨道；一个滑块块 = 一次“按下→松开”配对，块两端导出 press/release 事实；未闭合块显式标记并由校验拦截；支持横向缩放、时间标尺、网格吸附（默认 1 帧）；轨道由用户管理，收起时显示事件数、首帧、末帧与轨道数。

## 6. 模拟节点（桥）

- 消费配置区域边界输出交出的输入文档集合，调用任务系统执行模拟。
- 输出每个成员的 `session_id`，作为会话数据组交给分析区域。
- 状态反馈按成员展开：排队、运行中、成功、失败、取消；失败原因贴近对应成员。
- 参数为并发度与运行名称前缀；并发度默认 `min(4, CPU)`，成员小并行执行；第一版不支持结果复用，重跑即重新执行。
- 提供“取消整批”动作：排队成员立即取消，运行中成员跑完后标记取消并显示“正在停止”；成员级取消后续版本支持。
- 模拟节点不记录状态，职责只限分发与管理模拟；需要重新获取结果时从配置重新运行。

## 7. 分析区域

### 7.1 第一版节点清单

| 节点类型 | 职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| 数据提供 | 从结果库按名称、时间和状态选择已有运行，内部引用随节点配置保存 | 运行列表选择 | 会话数据组 |
| 查询 | 对应 StateQuery / EventQuery，选帧、路径、事件类型、过滤 | 会话数据 | 带定位信息的查询结果 |
| 指标 | 从事件流/序列派生总伤害、DPS、占比等，口径可见可改 | 查询/序列结果 | 指标结果 |
| 聚合 | 对一组展开结果求平均、最大、最小、标准差、P95、排序 | 指标结果组 | 汇总结果 |
| 对比 | 多个查询/指标结果并置成列 | 多路结果 | 对比结果 |
| 视图 | 展示终点；第一版为表格与时间轴 | 结果/对比结果 | 无（展示） |

- 序列节点第一版不独立暴露，作为指标节点的内部依赖；后续自定义指标时再放出。
- 图表与导出节点后续版本支持。

### 7.2 组展开语义

- 分析区域边界输入或数据提供节点给出一组会话后，查询与指标节点自动按成员展开，一个会话产出一个结果。
- 聚合节点把展开结果收拢；对比节点把多路结果并置。
- 分析区域不需要枚举/区间类特殊节点。

### 7.3 分析区域编辑器约定

- 分析区域边界输入显示外部连接状态与会话数，不作为独立节点占用画布空间。
- 数据提供节点内展开运行列表，按状态、时间或名称筛选并支持多选；列表使用用户可识别的运行信息，内部会话标识不在常规界面中展示。所选会话引用作为节点配置随工作流保存。
- 查询节点：状态查询/事件查询两种模式。状态查询选择帧（单帧或列表）与路径行；事件查询选择事件类型（多选）、帧范围、载荷路径、过滤条件（路径=值）与分页。路径为文本行，只做语法级检查。
- 指标节点：从预设指标池逐行添加（总伤害、DPS、最高/平均、占比、总治疗、治疗占比），每行显示口径说明；占比类指标选择分组维度；第一版不开放自定义公式。
- 聚合节点：统计操作多选（平均、最大、最小、标准差、P95）与排序；不做分组聚合。
- 对比节点：列由输入端口自动生成，标签可改、顺序可调；节点只做多列并置，对齐与聚合规则归视图节点。
- 表格视图：配置显示列、列顺序与排序；对比输入按列渲染，指标组按行渲染。
- 时间轴视图：选择伤害/治疗序列标记与事件类型（多选），配置时间范围、刻度（帧/秒）与横向缩放；状态曲线后续版本支持。

## 8. 连线语义

- 分支：一个输出连到多个下游时，数据复制到每个分支。
- 汇入顺序：多个上游连到同一节点时按节点输入端口顺序执行，先连先应用；用户可调整端口顺序。
- 禁止环路：画布必须是 DAG；检测到环时标出环上连线并阻止运行。
- 组标记：端口或连线显示“N 个值”，下游展开时显示展开倍数（×N）。
- 区域约束：跨区连线只允许经过模拟节点；数据语言不匹配的连线报错。
- 边界约束：跨区域连线只能连接区域边界端口与模拟节点。外部对象不能直接连接区域内节点，区域内节点也不能直接连接区域外对象。

## 9. 保存与重跑

- 工作流定义文件保存于 `<data_dir>/workflows/`，JSON 格式，包含：schema_version、配置/模拟/分析三部分的节点与连线、节点参数、视图配置、画布布局（区域与节点位置）。
- 编辑期临时状态（视口、选中、拖拽）不保存。
- 重跑模式：
  - 全部重跑：重新执行配置、模拟、分析整条链。
  - 仅分析重跑：使用数据提供节点从结果库提供会话，只重新执行分析部分。
  - 增量重跑第一版不做。
- 数据提供节点把所选会话作为节点配置保存；分析区域边界输入不保存会话，只接收模拟节点的运行时输出。
- 模拟节点不记录状态；重新获取模拟结果从配置重新运行。
- 分析是派生层，重跑分析不修改结果库真值。
- 保存必须由用户明确触发，界面持续显示未保存状态；运行不会隐式保存或清除未保存提示。
- 保存按钮保持普通样式，未保存状态由顶部栏徽标承担，不对按钮做警告强调。

## 10. 运行与导航

- 顶部栏提供“全部运行”，执行工作流整链；顶部栏不提供运行模式选择菜单。每个区域头部提供区域运行按钮，只执行该区域内容。重跑模式仍区分全部重跑与仅分析重跑，但入口由对应区域/分析能力承担。
- 执行期间节点按状态着色：未运行、等待、运行中、成功、失败、结果过期；错误贴近对应字段或节点；视图节点成功后直接显示结果。
- 运行期间禁止会改变工作流含义的编辑，避免执行中修改造成结果不一致；查看、平移、缩放、选择和问题跳转等非语义导航仍可使用。
- 字段和节点附近显示局部反馈，同时提供集中的问题列表用于汇总、筛选和跳转；两者不能互相替代。
- 导航范围：
  - 平移：鼠标中键拖拽（浏览器原型不验证中键手感）；空白画布左键拖拽做框选；点击选择区域/节点，拖动区域标题栏移动区域，拖动节点头部移动节点。
  - 缩放：滚轮以鼠标位置为中心，范围 25% ~ 400%；提供适应全部与定位选中。
  - 搜索节点定位。
  - 小地图：结构总览，显示区域、节点、连线、模拟桥与当前视口；支持定位选中和折叠/展开。
  - 书签第一版不做。
- 画布视觉：动态背景固定为氛围层；网格使用单层 24px 点阵；空画布显示“拖入区域开始”；小地图与左侧图标按钮位于画布右下角。
- 连线交互：从输出端口拖到输入端口建立连接；端口按数据语言区分标记，组端口显示“N 个值”；连线路径可手动调整。

## 11. 工程边界

- `frontend/` 通过 `server/` HTTP API 调用 `application/` 能力，不直接访问 SQLite，不组装仿真核心对象，不实现分析算法。配置区域边界预览调用 `POST /inputs/validate`，运行状态轮询 `GET /runs/{run_id}`。
- 画布实现需区分：WorkflowDefinition（持久化定义）、WorkflowEditorState（编辑与临时交互状态）、WorkflowValidator（类型、路径、环、覆盖与区域校验）、WorkflowRuntime（展开、应用、提交已展开成员并跟踪批次状态）。后三者落在 `frontend/`。
- 画布编辑状态不进入 `core/`。CLI 不运行工作流。后端批次 API 只接受 `(item_id, SimulationInput)`，工作流 JSON 仅作不透明存档。
- 工作流定义、节点类型与编辑器数据、批量配置变体、UI API 契约已创建于 `docs/契约/`。

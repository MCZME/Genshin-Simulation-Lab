# 星扩散反应契约

> 状态：正式规范。
> 本文固定星扩散独立反应的稳定标识、候选与元素消费、星辉风旋 State、伤害源与参与者账本、星扩散·风/冰伤害与去重、反应星烁复合公式请求边界及辉映·星扩散 Buff 契约。
> 最后更新：2026-09-12。

## 2. 候选与元素消费

星扩散只匹配以下条件同时满足的交互：

1. 请求携带 `reaction_capability:stellar_swirl`；
2. 请求携带上游确认的角色来源集合 `character_source_refs`；
3. 当前触发来源 `source_ref` 属于该角色集合；
4. 风元素命中正冰 Aura（`incoming_element = anemo`，`observed_aura_kind = cryo`）。

星扩散 `selection_priority` 为 `110`，高于普通扩散默认 `0`；无 capability 或合法角色触发来源时星候选不匹配，普通扩散继续生效。capability 存在但后续计划缺少空间锚点、binding 不一致或其他技术前提缺失时整批失败，不静默回退为普通扩散。

元素消费与普通扩散一致：

```text
incoming_consumed = min(incoming_amount, aura_amount × 2)
aura_consumed = incoming_consumed / 2
```

余量传递语义与普通扩散一致。

## 3. 星辉风旋 State

字段：

```text
instance_ref / space_entity_ref / subject_ref / level
last_reaction_source_ref / last_reaction_occurrence_ref
participants / created_frame / expires_at_frame / revision
```

约束：

- `instance_ref` 必须等于 `reaction-state:stellar-swirl-vortex:{创建 occurrence_ref}`，`space_entity_ref` 必须等于 `reaction_object:stellar_swirl_vortex:{创建 occurrence_ref}`；升级保留 `instance_ref` 与 `space_entity_ref`；
- `level ∈ [1, 6]`，创建时为 `1`；
- `expires_at_frame = created_frame + 180`（`180` 帧为约 `3` 秒实现基线）；升级不修改 `expires_at_frame`（不刷新爆炸计时，暂定基线）；
- 风旋按 `battle` 作用域全场唯一，同一时刻至多一个活动实例；同批次出现多个待建风旋时批次校验失败（6 级爆炸后的同帧新建除外：先终结旧风旋、后创建新风旋的批次内顺序合法）；
- State 创建/升级/移除与 Space 实体创建/更新/移除一一对应，由 `validate_stellar_swirl_vortex_space_bindings` / `validate_stellar_swirl_vortex_space_terminalizations` 在提交前校验；
- 到期或 6 级爆炸时由风旋到期协调器原子移除 State、Space 实体并物化冰爆炸 Effect group。

创建/升级/爆炸规则（由协调器形成确定性计划）：

- 无风旋时以反应目标当时位置创建等级 `1` 的风旋，锚点与角色位置无关；
- 有风旋时等级 `+1`：保留实例、锚点与爆炸计时，递增 `revision` 并更新账本（见第 4 节）；
- 等级达到 `6` 时立即终结当前风旋并物化爆炸；同一批次内后序目标事件按"无风旋"处理，创建等级 `1` 的新风旋并锚定该目标；
- 新风旋不继承旧风旋的账本、伤害源与等级。

## 4. 伤害源与参与者账本

State 的参与者账本为 `StellarSwirlParticipantEntry` 序列：

```text
participant_ref / first_reaction_frame / last_reaction_frame
```

- `participant_ref` 为角色主体 ref；同一角色只保留一条；
- 账本按参与者首次参与帧升序存储；结构性至多 `4` 名（队伍角色），超出时按首次参与帧升序保留前 `4`（确定性兜底）。

星扩散·风参与者认定：

- 触发者必入集合；
- 冰贡献者：反应发生时其冰贡献为目标冰 Aura 活跃贡献（剩余量 > 0）且被本次反应消费；判定以请求内冻结的 AuraView 贡献观察为准；
- 参与者按集合语义去重；不要求参与者持有星烁 capability；
- 冰被融化、星超导等其他反应消耗不产生参与者资格；仅施加附着未参与反应的角色不计入。

星扩散·冰参与者与伤害源认定：

- 参与者 = 生命周期内所有星扩散·风参与者集合的并集；
- 伤害源 = 生命周期内爆炸前最后一次星扩散·风的触发者（`last_reaction_source_ref`）；被风伤害去重挡掉的风事件与 6 级同帧引发爆炸的风事件都是合格候选；同帧多次风按稳定处理顺序取最后一条；
- 伤害源必在参与者集合内。

风伤害去重、等级累加、账本写入与"最后一次反应"认定彼此独立：去重只拦截伤害实例。

## 5. 星扩散·风伤害与去重 Gate

- 触发时立即对反应目标结算风元素反应星烁伤害：目标选择为 `CurrentSubjectSelection`，主攻击标签 `reaction.stellar_swirl.wind`，星烁基础系数 `0.75`，风元素、不附着元素、可暴击；
- 去重 Gate：`ReactionDamageGateDefinition(reaction_gate.stellar_swirl.wind, reaction_damage.stellar_swirl_wind, 30, 1)`；`30` 帧窗口为实现基线（资料仅给出"极短时间"），待来源化冻结；Gate 按目标判定，被挡目标是正常不伤害结果，不是错误；
- 去重不影响反应发生、元素消费、风旋等级累加、参与者计入与伤害源认定；
- 多目标同帧按稳定 `subject_ref` 顺序逐目标处理，每个目标事件独立执行去重判定与等级累加。

## 6. 星扩散·冰爆炸与冰附着

- 爆炸不是触发反应：不发 `REACTION_OCCURRED`，无反应触发者；
- 伤害源 = `last_reaction_source_ref`；参与者 = 账本并集；
- 爆炸中心为风旋 Space 实体位置；目标选择 `AreaAroundPositionSelection`：等级 `1~2` 半径 `6`、等级 `3~6` 半径 `8`；圆柱高度 `4` 仅作强类型资料记录，当前空间查询投影为 X/Z 圆、高度不参与判定；
- 范围内全部有效目标承受冰元素反应星烁伤害：主攻击标签 `reaction.stellar_swirl.ice`，星烁基础系数等级 `1~2` 为 `2`、等级 `3~6` 为 `3`，可暴击；
- 爆炸对命中目标附着 `1U` 冰元素，经 ReactionGeneratedImpactBatch → AuraApplicationRequest 通道施加，`source_ref` 为伤害源；后续反应触发者随之，无需特殊接线；
- 爆炸 Effect group 以 `NEXT_SETTLEMENT_ROUND` 轮次执行；到期爆炸与 6 级提前爆炸产出同一 Effect 形态；
- 爆炸命中目标与参与者集合互不关联。

## 7. 反应星烁复合公式与请求边界

`damage_formula.stellar_reaction` 的 `reaction_composite` 模式本期启用（星超导继续 `character_direct`）：

- `StellarReactionDamageInput.mode = "reaction_composite"`；新增 `reaction_base_value` 与参与者列表字段；参与者字段包含参与者主体 ref、自身 `reaction_base_value` 与星烁专属区间输入；
- `reaction_base_value` 按参与者自身等级查等级系数表（与剧变同源），在观察期冻结；
- 逐参与者单人结算：以参与者 `reaction_base_value` 替换 `scaling_value`，星烁基础系数取输入的 `stellar_base_multiplier`（风 `0.75`、冰 `2/3`）；
- 每名参与者使用独立 DamageRequest（`request_id` 带参与者标识、`source_ref` 为参与者）与独立结算会话；元素精通、暴击（注入式 `CriticalDecisionProvider` 逐参与者决策）实时读取并生成独立审计；同一目标的参与者组分共享同一抗性区；
- 按折前伤害从高到低稳定排序（同值按参与者主体 id），最多保留 `4` 名；
- 权重按名次固定分配：第 `1` 名 `0.60`、第 `2` 名 `0.30`、第 `3/4` 名 `0.05`；不按参与人数重归一化（与月曜复合实现同构）；
- 星烁基础增伤、星烁增伤、星烁大权区、反应星烁羽毛区与星烁擢升使用强类型字段，不通过普通 `DamageModifierTerm` 伪造；
- 公式实现无状态，不读取 Buff、ReactionState 或协调器；
- 结算结果写入 `StellarReactionDamageResolution`（含逐参与者组分、权重与聚合审计），`DamageResult.stellar_reaction_resolution` 承载；`DAMAGE_RESOLVED` 审计在 `reaction` 下以 `kind: "stellar"` 序列化；
- 星扩散伤害请求经 `DamageRequestHandler` 的 `stellar_reactions`（按目标映射）输入通道提交，对应 ImpactRequest 的 DamageProfile 必须选择星烁公式（`reaction.stellar_swirl.wind` / `reaction.stellar_swirl.ice` → `damage_formula.stellar_reaction`）；
- 星烁复合伤害的暴击由公式内逐参与者决策承担，Impact 层不启用整体暴击。

## 8. 辉映·星扩散 Buff

辉映·星扩散 Buff（`buff.reaction.stellar_swirl.radiance`）契约：

- 目标主体为角色；应用策略 `REFRESH`、数值刷新 `REPLACE_LATEST`、至多 `1` 层；conflict key 为 `buff_conflict.reaction.stellar_swirl.radiance`；
- 携带属性词条模板：`stellar.swirl.radiance.direct_base_multiplier` → `stellar.swirl.direct_base_multiplier`，`FLAT_ADD`，固定值 `1.0`；
- 每次星扩散·风触发后，协调器在同一交互批次内为具备辉映·星扩散资格的角色统一申请或刷新；`duration_frames` 满足 `frame + duration = frame + 480`（`480` 帧为约 `8` 秒实现基线）；多次触发按 `REFRESH` 顺延；
- 目标集合由辉映·星扩散资格证据决定，经 capability 证据模型承载；机制首期由测试构造资格证据，具体角色与资格 key 粒度在角色资产接入阶段定案；
- 与辉映·星超导 Buff 可同时存在；同一角色同时满足两种辉映状态条件时只有辉映·星超导生效，由角色侧启用逻辑的读取优先级执行，Buff 层不做跨 Definition 互斥；
- `source_context` 固定为 `RuntimeSourceRef(MECHANIC, "reaction.stellar_swirl", battle)`，保证刷新兼容。

## 9. 事务、事实与错误边界

星扩散候选、风旋 State/Space 创建与升级、账本写入、爆炸 Effect 物化与到期移除均使用 `prepare -> validate -> commit`。State、Space 与事实的前值/版本任一 stale 时，整批失败且不得部分提交；binding 不一致由风旋 binding 校验在提交前拒绝。

必须记录：风触发时的 `REACTION_OCCURRED`、风旋变化的 `REACTION_STATE_CHANGED`、`ELEMENTAL_INTERACTION_RESOLVED`、风/冰伤害的 `DAMAGE_RESOLVED`（stellar 审计）与风旋 Space 实体的 `SPACE_ENTITY_CREATED` / `SPACE_ENTITY_REMOVED`；爆炸不发 occurrence、不伪造触发反应。

显式失败：同批次非法的多风旋创建（非 6 级爆炸后续）、等级越界、binding 不一致、重复提交同一 occurrence、升级缩短存在时间。正常非伤害结果：被去重挡掉的风伤害、风旋到期爆炸。

同帧多目标的处理顺序按稳定 `subject_ref` 排序；相同配置、资产版本、输入、帧顺序和随机种子必须得到相同的风旋序列、账本、伤害源认定与伤害结果。

## 10. 当前非目标与验收入口

契约不包含：

- 风元素自附着方向（`stellar_incoming_cryo_on_anemo`）：依赖 `AuraKind` 扩展 ANEMO，需单独决策；
- 风旋爆炸命中角色的跳跃能力 Buff：位置级队伍作用域挂载身份（`AttributeSubjectKind.ACTIVE_CHARACTER`，见[状态效果系统契约](../../状态效果系统契约.md)第 30 节）已可用，但 Movement 尚无跳跃能力模型，且命中范围、持续时间与"完成一次跳跃后消失"的消耗语义仍未来源化确认，本期仅预留；
- 爆炸冲击 Impact 语义（削韧 `60/80`、`Air,100,600` 冲击、停滞与 `HitDirection`）：属 Impact/命中层语义，不在本契约范围；资料已记录，接入切片另行评估；
- 角色直伤星扩散的正式 content 技能模组（桑多涅、奥黛塔等）；
- 辉映·星扩散资格的具体角色与 key 粒度定案；
- `180` 帧、`480` 帧、去重窗口 `30` 帧的精确数值冻结。

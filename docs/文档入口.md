# 文档入口

本文档目录用于保存项目重建、架构设计、开发规范与长期契约。文档默认使用中文正文，文件和目录名也使用中文命名，便于按语义浏览和维护。

## 目录结构

```text
docs/
├── 文档入口.md
├── 架构/
│   ├── 当前项目架构流程图.md
│   ├── 日志系统设计.md
│   ├── 资产系统设计.md
│   ├── 仿真任务执行模型.md
│   ├── 事件系统/
│   │   ├── 系统设计.md
│   │   └── 事件类型.md
│   └── 模块边界设计.md
├── 契约/
│   ├── 资产数据库设计.md
│   ├── 仿真配置契约与最小闭环.md
│   └── 输入轨迹契约草案.md
├── 决策/
│   └── 项目决策记录.md
└── 工程/
    ├── 工程规范.md
    ├── AI协作规范.md
    ├── 旧项目能力盘点.md
    └── 迁移阶段安排.md
```

## 文档分区

- `架构/`：长期架构设计、模块边界、运行时结构、系统间依赖关系。
- `契约/`：稳定数据契约，例如配置文件、资产库 schema、结果数据模型。
- `决策/`：已经确认的高层决策、ADR 与阶段性结论。
- `工程/`：开发流程、测试策略、迁移策略、质量工具和贡献规范。

## 归档原则

- 已确认且会长期影响实现的内容，放入 `架构/`、`契约/` 或 `决策/`。
- 开发执行层面的规则，放入 `工程/`。
- 临时讨论稿若尚未形成结论，先不要进入长期文档；需要保留时在文档开头标注状态。
- 文档中的路径引用使用相对链接。

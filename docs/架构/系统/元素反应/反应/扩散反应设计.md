# 扩散反应设计

> 状态：已实现
> 最后更新：2026-08-01
> 对应契约：[扩散反应契约](../../../../契约/元素反应/反应/扩散反应契约.md)

## 1. 定位

扩散是由风元素命中触发的剧变反应。它先在中心目标结算一次扩散伤害，再把被扩散元素作为派生命中发射到范围内的其他目标。

扩散同时跨越反应、目标选择、元素附着和伤害四个领域：

- 反应系统识别方向、消耗中心 Aura，并产生确定的派生效果；
- 协调层按轮次选择范围目标并提交派生命中；
- 元素附着系统处理派生命中携带的火、水、雷或冰元素；
- 伤害系统结算扩散伤害，以及派生命中可能触发的蒸发或融化增幅。

扩散不会在目标上留下风元素 Aura。

## 2. 反应方向

普通扩散支持以下方向：

| 输入方向 | 扩散元素 |
| --- | --- |
| 风命中火 Aura | 火 |
| 风命中水 Aura | 水 |
| 风命中雷 Aura | 雷 |
| 风命中冰 Aura | 冰 |
| 风命中冻结 Aura | 冰 |

冻结 Aura 只改变中心状态的消耗方式；其派生命中的输出元素仍为冰。

## 3. 中心结算

设通过 ICD 后的风元素量为 `W`，当前可反应 Aura 量为 `A`：

```text
incoming_consumed = min(W, 2 * A)
aura_consumed = incoming_consumed / 2
remaining_incoming = W - incoming_consumed
remaining_aura = A - aura_consumed
```

一次普通扩散 occurrence 产生：

1. 中心目标上的扩散伤害，基础倍率为 `0.6`；
2. 一次范围发射请求，携带被扩散元素和派生元素量。

派生元素量按反应前的 `W`、`A` 计算：

```text
2 * A > W  时：1.25 * W + 0.95
2 * A <= W 时：1.25 * A + 0.95
```

等量边界属于第二个分支。

## 4. 范围发射

范围目标策略为以中心目标为圆心、XZ 平面半径 `6` 的圆形范围：

- 排除中心目标；
- 冻结范围内的候选目标，再逐目标评估关系与能力；
- 结果按稳定 `subject_ref` 排序；
- 当前不设目标数量上限。

派生命中的组成取决于扩散元素：

| 扩散元素 | 范围伤害 | 范围附着 |
| --- | --- | --- |
| 火 | 有 | 有 |
| 水 | 无 | 有 |
| 雷 | 有 | 有 |
| 冰 | 有 | 有 |

派生附着不经过攻击自身的 ICD。若派生元素未触发反应，则按普通附着规则保留并应用标准元素量衰减。

伤害与附着的目标能力分别判断。目标支持伤害但不支持 Aura 时，范围伤害仍可结算，附着分量记录为不支持；非敌对关系会阻止该命中中存在的两个分量。

## 5. 伤害语义

扩散伤害使用派生冲击发生时捕获的来源观察值：

```text
damage = level_multiplier
       * 0.6
       * (1 + 16 * EM / (EM + 2000) + reaction_bonus)
       * target_resistance_multiplier
```

- 伤害元素与被扩散元素一致；
- 不暴击；
- 不携带可用于附着的元素量；
- 不读取攻击、防御区或普通增伤区；
- 当前扩散专属反应加成为 `0`；
- 90 级、0 精通、抗性乘区为 `1` 时，中心或单次范围伤害为 `868.1118`。

火、水、雷、冰各自使用独立伤害门控。门控键由来源、目标、伤害元素与组别共同确定，窗口为 `30/2`；中心伤害与范围伤害共享同元素门控。门控只抑制伤害，不撤销范围附着或由它触发的后续反应。

范围派生伤害使用 `SECONDARY_AMPLIFYING` 语义，因此火扩散伤害命中水 Aura、冰扩散伤害命中火 Aura 等场景可以继续触发蒸发或融化。增幅结算读取派生冲击捕获的原始风攻击者属性。

## 6. 双扩散

中心目标出现特定共存状态时，一次风命中可产生两个扩散 occurrence：

- 雷 + 水：固定按雷、再水结算；
- 水 + 冻结：固定按水、再冻结结算，后者输出冰；
- 隐藏冰 + 冻结：只产生一次冰扩散 occurrence 和一次冰发射；冻结状态的第二条消耗作为无所有者状态迁移处理。

第二步只有在第一步耗尽其 Aura 且仍有风元素余量时才执行。雷水与水冻结双扩散中，两步发射共享按第二步反应前状态计算出的派生元素量。

派生命中落到无 Aura 目标时，雷水和水冰使用专门的同时附着策略，分别建立雷水共存和水冰冻结状态。其他已有 Aura 组合仍按正常的单次派生命中顺序处理；未支持的同时应用组合稳定报错。

## 7. 批次与轮次

扩散 occurrence 通过 `ReactionEffectGroup` 表达中心伤害，通过 `ReactionGeneratedImpactBatch` 表达范围发射、来源观察和一个或多个 occurrence 的因果信息。协调器以确定性轮次处理派生命中：

1. 第 0 轮提交根命中的反应消耗；
2. 第 1 轮处理中心伤害与范围发射；
3. 后续轮次处理派生命中触发的反应及其子效果。

队列上限为 64 轮。每个派生命中批次单独原子提交；后续批次失败不会回滚此前已提交的独立批次。

## 9. 非目标

当前不处理：

- 草元素扩散；
- 环境或自身附着；
- 染色、元素转化或技能吸收逻辑；
- 风套等具体内容效果；
- 击退、硬直、削韧和空间位移；
- 对扩散伤害开放暴击或普通伤害区修改。

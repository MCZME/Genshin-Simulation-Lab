# 冻结反应设计

> 状态：已实现。本文描述普通水冰冻结、派生冻元素与连续冻结生命周期。

最后更新：2026-08-03

## 1. 定位

普通冻结是耦合 Aura 与 ReactionState 的持续状态反应。水、冰交互先形成冻结 occurrence；协调器再把派生 `FROZEN` Aura 与 `FrozenState` 作为同一跨系统事务准备、校验和提交。

代码落点：

```text
core/systems/reaction/mechanics/frozen/
core/systems/reaction/states.py
core/coordination/elemental_reaction/links.py
```

冻结本身不造成伤害。无伤害元素施加也能触发冻结。

## 2. 方向与元素量

显式方向：

```text
incoming_hydro_on_cryo
incoming_cryo_on_hydro
```

设 ICD 后后手预算为 `I`，匹配的先手 Aura 为 `A`：

```text
reaction_amount = min(I, A)
frozen_amount = 2 * reaction_amount
incoming_remaining = I - reaction_amount
aura_remaining = A - reaction_amount
```

`reaction_amount` 只计算双方实际参与的 `1:1` 消费。后手剩余预算不会在冻结步骤结束后形成普通持久 Aura；先手剩余水或冰作为藏元素保留。

## 3. 派生 Aura、藏元素与状态

冻结运行态由三部分组成：

```text
普通水或冰 Aura  -> 藏元素，可能不存在
FROZEN Aura       -> 冻元素量与衰减的唯一真值
FrozenState       -> Link、衰减速率历史和下一必需处理帧
```

`FROZEN` 不是普通冰。它可以与藏水或藏冰共存，通过唯一 `ElementalStateLinkRef` 与同主体 `FrozenState` 关联。提交后不得只存在 Aura 或只存在 State，也不得出现 Link 不一致。

`FrozenState` 不复制冻元素量。其他系统需要判断目标是否冻结时，应读取 Reaction 的窄观察值，不在 Buff、角色状态或内容层复制第二份状态。

## 4. 冻结抗性

冻结抗性是协调器提供的只读 `FreezeResistanceObservation`，值域为 `[0, 1]`：

```text
effective_frozen_amount = frozen_amount * (1 - freeze_resistance)
```

当前生产默认冻结抗性固定为 `0.0`。没有专用观察值时，协调器构造 `0.0` 观察；当前不增加 `AttributeKey`、配置字段或内容适配器。

抗性只作用于本次新生成的冻元素量。`freeze_resistance = 1.0` 时 occurrence 和水冰消费仍成立，但不创建持久 `FROZEN` Aura 或 `FrozenState`。

## 5. 连续冻结

冻结衰减速率最低为 `0.4 GU/s`。活动冻结期间每秒增加 `0.1 GU/s`；解冻后每秒恢复 `0.2 GU/s`，最低回落到 `0.4 GU/s`。

给定本次开始时的衰减速率 `v` 和已经应用抗性的有效冻元素量 `D`：

```text
duration_seconds = (sqrt(v^2 + 0.2 * D) - v) / 0.1
```

持续时间按固定 `60 FPS` 向上取整为帧，活动区间使用半开语义。

活动冻结再次成立时：

- 先投影当前帧剩余冻元素与当前衰减速率；
- 新产生冻元素先独立应用本次冻结抗性；
- 最终冻元素量取当前剩余量与新有效量的较大者；
- 延续当前衰减速率并重新计算到期帧。

## 6. 解冻与恢复历史

自然到期或碎冰会原子移除 `FROZEN` Aura 与 `FrozenState`。解冻瞬间的衰减速率高于最低 `0.4` 时写入 `FreezeRecoveryState`，供下一次冻结惰性投影；速率已经为最低值时不创建恢复记录。

`FreezeRecoveryState`：

- 只在存在高于最低值的速率历史时创建，不表示目标仍处于冻结；
- 不持有 Aura Link；
- `next_required_frame = None`，不会单独延长仿真；
- 新冻结建立时被消费并由新的活动状态接管。

## 7. 候选顺序

冻结参与多步骤候选时使用虚拟投影视图，不依赖 Registry 顺序：

- 钝击碎冰先移除冻元素，再让同一 Impact 的元素预算读取暴露出的藏元素；
- 火、雷与藏冰和冻元素的组合顺序由公共候选规则显式声明；
- 序列中的每一步读取前一步投影后的 Aura 与 State。

具体碎冰顺序见[碎冰反应设计](./碎冰反应设计.md)。

## 8. 非目标与验证

冻结状态目前只提供机制事实和生命周期，不实现敌人行动、动画、技能释放、硬直、削韧、击退、停滞或空间位移。

长期验证覆盖两个方向、无伤害施加、`2 * min(I, A)`、藏元素保留、默认/完全冻结抗性、连续冻结刷新、自然到期、恢复历史、Link 原子性和 stale plan 零提交。

稳定字段见[冻结反应契约](../../../../契约/元素反应/反应/冻结反应契约.md)。

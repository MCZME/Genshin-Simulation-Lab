# 节点类型与编辑器数据契约

> 状态：已确认（2026-08-17）；实现时按此契约注册节点类型。
> 关联：[工作流定义契约](./工作流定义契约.md)、[批量配置变体契约](./批量配置变体契约.md)。

## 1. 职责与分工

- 语义注册表在 `application/workflow/`：节点类型、端口模型、片段形状、参数 schema、区域约束与节点级校验。
- 编辑器组件映射在 `frontend/`：`node_kind -> React 组件`、图标、默认尺寸、面板排序等展示元数据。
- 两侧以稳定 `node_kind` 为公共 key，互不 import。
- 显式注册，不自动扫描；未注册 kind 在加载/校验阶段报错。

## 2. NodeKindSpec

每个节点类型是一个描述对象，至少包含：

| 字段 | 含义 |
| --- | --- |
| `kind` | 稳定 key，冻结后只追加不改名 |
| `display_name` | 用户可识别名称 |
| `region` | `configuration` / `analysis` / `bridge` |
| 端口模型 | 输入输出端口、数据语言、单值/组基数、连接数约束 |
| 片段形状 | 默认目标路径与参数形状；只声明路径，不读取 SimulationInput schema |
| 参数 schema | 类型化节点参数，供编辑器生成表单与校验 |
| 节点级校验 | 该类型特有的校验规则 |

## 3. MVP 节点注册表

配置区域（`configuration`）：

| kind | 默认路径 | 关键参数 |
| --- | --- | --- |
| `root` | 无 | 文件路径（可选） |
| `meta` | `meta` | 无 |
| `character` | `team[i].character` | 槽位 i |
| `weapon` | `team[i].weapon` | 槽位 i |
| `artifact` | `team[i].artifacts` | 槽位 i |
| `target` | `scene.targets[i]` | 目标索引 i |
| `input_trace` | `input_trace` | 无 |
| `run_options` | `run_options` | 无 |
| `enum` | 用户指定 | 路径、取值列表、标签 |
| `range` | 用户指定 | 路径、起点、终点、步长、标签 |

桥（`bridge`）：

| kind | 职责 |
| --- | --- |
| `simulation` | 消费输入文档集合，按成员执行，输出会话组 |

分析区域节点（查询/指标/聚合/对比/视图/数据提供）不在 MVP 注册；后续只做注册新增，不重构画布。

## 4. 参数 schema

参数 schema 使用类型化字段，供前端生成表单：

- `string` / `integer` / `number` / `boolean` / `text`
- `asset_ref`：引用资产类型，编辑器使用资产搜索选择器
- `list`：有序取值列表（枚举节点）
- `range`：起点/终点/步长（区间节点）
- `object` / `json_fragment`：JSON 片段

常规界面展示显示名称与状态说明，不暴露 `asset_key`、`handler_key`、JSON 路径（路径在高级编辑中可见可改）。

## 5. 端口模型

- 端口有稳定 `port_id`；常见形态为单输入单输出，节点可声明多个独立端口。
- 基数：单值输出 / 组输出。组输出触发下游展开。
- 成员投影端口：枚举/区间节点可展开单个成员端口，绑定稳定 `item_id`；折叠后已有连线保留并显示成员标签。
- 多路独立输出重新汇入时不得静默恢复成组、拼接或叉乘；汇入语义由下游端口或显式节点声明。

## 6. 编辑器数据契约

前端注册表为每个 `node_kind` 提供：

- 编辑器组件（React）
- 图标与节点类型色
- 默认节点宽度与最小/最大尺寸
- 画布对象面板排序与分组
- 收起时的摘要渲染规则

展示元数据不进入 `application/workflow/`，不参与校验与运行。

## 7. 特殊行为

- 配置区域边界输出：区域模型内置，不进入节点注册表。
- 模拟节点：任务分发、成员状态、整批取消，绑定 `simulation` kind 的特殊行为。
- 视图节点：分析区域实现时设计，MVP 不注册。

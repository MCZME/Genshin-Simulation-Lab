# 碎冰反应设计

> 状态：已实现。本文描述普通钝击碎冰、冻结状态消费和独立物理剧变伤害。

最后更新：2026-08-03

## 1. 定位

普通碎冰是 `STATE_TRIGGER` 反应。它不依赖正元素施加，而是读取目标级 Impact 的 `StrikeType.BLUNT`、活动 `FrozenState` 和 linked `FROZEN` Aura。

代码落点：

```text
core/systems/reaction/mechanics/shattered/mechanic.py
```

## 2. 触发与状态消费

碎冰成立必须同时满足：

```text
trigger_context.strike_type = BLUNT
observed_frozen_state 存在
linked FROZEN Aura 的当前量大于 0
```

元素量可以为零。Reaction 不从武器类型、角色、攻击标签、动画或最终伤害值推导钝击资格。

碎冰 occurrence 成立后完整移除 linked `FROZEN` Aura 与 `FrozenState`，不执行部分扣减；藏水或藏冰不被碎冰直接消费。解冻速率高于最低 `0.4` 时留下惰性的 `FreezeRecoveryState`，否则不创建恢复记录。

## 3. 同一命中的候选顺序

碎冰优先于同一目标级 Impact 携带元素形成的其他反应：

```text
读取冻结投影
-> 碎冰 occurrence
-> 移除 FROZEN Aura 与 FrozenState
-> 暴露藏水或藏冰
-> 使用同一后手元素预算继续候选序列
```

因此钝击火命中可以先碎冰，再对暴露的藏水形成蒸发；此顺序由 `ReactionDecisionSequence` 明确表达，不由事件回调递归触发。

## 4. 独立物理伤害

碎冰 occurrence 冻结一个当前主体选择的 `GeneratedDamageImpactEffect`，在下一 settlement round 执行：

```text
damage element = physical
base multiplier = 3.0
reaction bonus = 0.0
elemental amount = 0
can crit = false
strike type = none
```

机制 Effect 显式携带 `transformative_base_multiplier = 3.0`。协调器只转换统一 Damage 输入，不按 reaction key 或 damage kind 推导碎冰倍率。

最终伤害使用共享剧变公式、触发来源等级和元素精通，以及目标当前物理抗性。来源缩放基础在 occurrence 形成时捕获。

## 5. Damage Gate

碎冰伤害使用来源、目标和 damage kind 分槽的 30 帧最多两次窗口：

```text
window_frames = 30
max_damage_instances = 2
```

第 `N` 帧前两次允许，第三次及以后阻止；`N + 30` 建立新窗口。Gate blocked 只阻止独立物理伤害，不撤销碎冰 occurrence、冻结解除、恢复历史或后续藏元素候选。

## 6. 事务与轮次

原始命中的 batch 原子准备碎冰 occurrence、Aura/State 移除和后续元素候选。碎冰 Damage Effect 在该 batch 提交后进入下一 settlement round；它拥有独立 Gate 和 Damage 事务，失败不回滚已经提交的原始命中 batch。

超载范围伤害携带 `BLUNT`，因此可以在其 Effect Group 内触发碎冰。即使超载自己的 Damage Gate blocked，钝击语义仍可以解除冻结并排入碎冰伤害。

## 7. 非目标与验证

碎冰不实现削韧、硬直、冲击、击退、停滞、hitlag 或空间位移，也不预建具体武器和技能名单。

长期验证覆盖零元素量钝击、一次 Impact 一次 occurrence、完整解除冻结、藏元素保留、同击后续反应、物理倍率与抗性、`30/2` Gate、Gate 与状态消费解耦，以及跨领域预检失败时零提交。

稳定字段见[碎冰反应契约](../../../../契约/元素反应/反应/碎冰反应契约.md)。

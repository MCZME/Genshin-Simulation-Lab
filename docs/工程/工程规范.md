# 工程规范

本目录保存项目开发、测试、迁移、质量控制和历史交付资料。当前工程规则与历史实现规划必须分开解释。

## 1. 质量工具

- `pytest`：测试主框架。
- `pytest-cov`：覆盖率统计。
- `ruff`：代码检查、导入排序和格式化。
- `pyright`：静态类型检查。

常用命令：

```powershell
uv run pytest
uv run pytest --cov=genshin_sim
uv run ruff check
uv run ruff format
uv run pyright
```

## 4. Golden case 组织

`tests/golden/` 按“稳定业务领域 -> 机制或跨机制流程”组织，不按第一版、第二版等交付批次组织。目录、文件名、测试函数名和测试数据标识都不得使用版本时间线作为分类依据；历史版本和迁移来源只记录在文档或必要注释中。

当前一级领域为 `damage/` 与 `reactions/`。命名、拆分以及与 unit/integration 测试的边界，直接以现有 golden case 目录和正式契约验收入口为准。

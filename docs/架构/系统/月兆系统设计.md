# 月兆系统设计

> 状态：正式规范。
> 本文说明 `core/systems/moonsign/` 月兆领域的职责：月兆等级与角色识别、非月兆角色月曜增伤记录、向月曜反应注入增伤，以及装配与事件边界。
> 最后更新：2026-09-05。

等级枚举、元素缩放公式、领域模型、事件载荷与识别装配规则以[月兆契约](../../契约/月兆契约.md)为真值，本文不重复维护。

## 1. 定位

`core/systems/moonsign/` 是挪德卡徕地区效果（月兆）领域。它唯一拥有：

- 月兆等级（无 / 初辉 / 满辉）与月兆角色集合。
- 非月兆角色施放元素战技 / 元素爆发后的覆盖式月曜增伤记录。
- 供伤害侧查询的月曜增伤只读端口与产出槽位词条的伤害修饰 provider。

月兆角色识别使用角色 `ContentUnit.metadata` 的 `moonsign: true` 标记，不改资产库 schema。

## 2. 规则

月兆等级按队伍中月兆角色数量判定：1 名为初辉，2 名及以上为满辉；满辉同时包含初辉语义。满辉时，非月兆角色施放元素战技或元素爆发后的 1200 帧内，按角色自身元素为附近所有角色的月曜反应伤害提供增伤，至多 36%；无法叠加，后施放覆盖先施放，到期自动清除。触发条件、时长、上限与元素缩放公式见[月兆契约](../../契约/月兆契约.md)。

## 3. 结构

```text
core/systems/moonsign/
├── models.py        MoonsignLevel / MoonsignScaling / MoonsignStatSnapshot /
│                    MoonsignBonusRecord
├── resolver.py      等级判定与非月兆月曜增伤纯公式
├── store.py         MoonsignStore：等级、月兆角色集合与增伤记录唯一真值
├── runtime.py       MoonsignRuntime：FACT_RESPONSE 消费 ACTION_STARTED、
│                    应用 / 到期清理、快照与端口
├── ports.py         LunarDamageBonusPort / MoonsignLevelReadPort
├── providers.py     MoonsignLunarBonusProvider：把当前增伤写成月曜公式
│                    位置 5 的 lunar_reaction_bonus_add 词条
├── snapshots.py     MoonsignSnapshot
└── errors.py        领域错误
```

## 4. 事件与事实

- `ACTION_STARTED`：动作实例进入 RUNNING 时由动作系统发布，载荷含 `action_key`、`owner_slot` 与 `ability_key`。
- `MOONSIGN_LEVEL_SET`：Runtime 在首个模拟帧发布一次。
- `MOONSIGN_BONUS_APPLIED`：满辉下非月兆角色 E / Q 触发增伤时发布。
- `MOONSIGN_BONUS_EXPIRED`：增伤到期清除时发布。

## 5. 月曜伤害注入

增伤以 `DamageModifierProvider` 产出词条的方式进入伤害数值：`MoonsignLunarBonusProvider` 在月曜伤害结算时用只读端口 `LunarDamageBonusPort` 读取查询帧的生效值，产出一个 `lunar_reaction_bonus_add` 词条，由月曜公式并入位置 5（反应加成）的槽位账单。领域不再拥有"算好数值再写进强类型字段"的注入通道。

- 公式自筛：`lunar_reaction_bonus_add` 只属于月曜公式；provider 按 `formula_key` 自筛，否则通用直伤、剧变与星烁查询会被白名单硬拒绝并让整次结算失败。
- 端口绑定：`build_moonsign_bundle()` 内完成绑定；未绑定时 provider 不成交，因此装配期早于绑定的伤害查询不受影响。
- 数值等价：词条值与增伤小数倍率相同，落在 `reaction_bonus 基线 + Σ 词条` 的同一括号内，无月兆或未生效时为 0，不影响既有月反应 golden case。
- 逐参与者语义：provider 不按来源过滤，因此复合模式下对每个参与者各贡献一次（队伍级效果的既有语义）。

## 6. 装配

```text
角色 ContentUnit.metadata.moonsign == true
-> application/assembly/moonsign.py build_moonsign_bundle()
   -> MoonsignStore.set_level（组装期一次）
   -> MoonsignRuntime（属性解析器、元素缩放参数、元素槽位表）
   -> MoonsignLunarBonusProvider(bonus_port=runtime)
-> RuntimeAssembler
   -> FACT_RESPONSE 注册 moonsign runtime
   -> DamageModifierIndex 注册月曜增伤 provider（与内容侧、共鸣侧 provider 并列）
   -> 快照 provider "moonsign"
```

## 7. 不覆盖

- 月兆角色专属初辉 / 满辉强化：由角色 content 经 `MoonsignLevelReadPort` 条件解锁。
- 「新月之拥」：确认不进 `SimulationInput`。

# 碎冰反应契约

> 状态：已实现。冻结普通钝击碎冰的状态资格、消费顺序、物理剧变伤害与 Damage Gate。

最后更新：2026-08-01

## 1. 稳定 key

| 用途 | 值 |
| --- | --- |
| Reaction | `reaction.shattered` |
| Handler | `reaction_handler.shattered` |
| Direction | `blunt_on_frozen` |
| Profile | `reaction_profile.shattered` |
| Damage Profile | `damage_profile.reaction.shattered` |
| Damage kind | `reaction_damage.shattered` |
| Damage Gate | `reaction_gate.shattered.damage` |

## 2. 进入方式与资格

碎冰 Definition 使用 `ReactionEntryKind.STATE_TRIGGER`，可以不声明元素签名和方向 Profile。请求必须具有：

```text
trigger_context.strike_type = StrikeType.BLUNT
observed_frozen_state
observed_aura.FROZEN.current_amount > 0
```

`observed_frozen_state` 必须与 `FROZEN` Aura 通过同一 Link 关联。`incoming_element = None`、`incoming_amount = 0` 是合法输入；没有钝击证据或活动冻结时返回正常空结果。

## 3. 元素与状态变化

碎冰的 `ElementalTransitionEffect` 固定：

```text
aura_kind = FROZEN
incoming_consumed = 0
aura_consumed = aura_before
aura_remaining = 0
```

协调器必须在同一 batch 完整移除 `FROZEN` Aura 与 `FrozenState`。当前衰减速率大于 `0.4` 时创建 `FreezeRecoveryState`，否则不创建恢复记录。藏水或藏冰不在该 transition 中消费。

## 4. Damage Effect

每个碎冰 occurrence 产生一个当前主体选择的下一 settlement round Effect Group，其中只有一个 `GeneratedDamageImpactEffect`：

```text
damage_element = physical
transformative_base_multiplier = 3.0
reaction_bonus = 0.0
elemental_amount = 0
can_crit = false
strike_type = None
```

倍率必须由 Effect 显式携带；协调器不得按 `reaction_key`、`damage_kind_key` 或 Damage Profile 补出 `3.0`。伤害读取目标物理抗性并遵守[剧变反应伤害契约](../剧变反应伤害契约.md)。

## 5. Damage Gate

```text
window_frames = 30
max_damage_instances = 2
```

Gate slot 由 `gate_definition_key + trigger_source_ref + damage_target_ref + damage_kind_key` 唯一确定。

- 同一窗口前两次允许，第三次及以后阻止；
- `frame >= ready_frame` 时建立新窗口；
- blocked 不修改 Gate Record、revision 或 Store version；
- blocked 只阻止碎冰 Damage，不撤销 occurrence、Aura/State 移除、恢复历史或后续候选。

## 6. 候选顺序与轮次

同一 Impact 同时具有 `BLUNT` 和正元素施加时：

```text
step 0 = shattered
step 1+ = 基于暴露藏元素继续匹配的元素反应
```

同一目标级 Impact 最多形成一次普通碎冰 occurrence。碎冰 Damage Effect 只能进入严格更大的 settlement round，不通过 EventEngine 回调递归结算。

## 7. 排除项、失败与验证

钝击只表达碎冰资格，不包含削韧、硬直、冲击、击退、停滞、hitlag 或空间位移。

缺少剧变来源观察、Damage Profile、Gate Definition、物理抗性输入或 Link 前值不一致必须在写入前失败。Gate blocked 是正常目标结果。

# 超载反应契约

> 状态：已实现。冻结普通火雷超载的方向、元素量、范围伤害、Gate 与钝击语义。

最后更新：2026-07-31

## 1. 稳定 key

| 用途 | 值 |
| --- | --- |
| Reaction | `reaction.overloaded` |
| Handler | `reaction_handler.overloaded` |
| Damage Profile | `damage_profile.reaction.overloaded` |
| Damage kind | `reaction_damage.overloaded` |
| Damage Gate | `reaction_gate.overloaded.damage` |

方向与 Profile：

| direction_key | profile_key |
| --- | --- |
| `incoming_pyro_on_electro` | `reaction_profile.overloaded.incoming_pyro_on_electro` |
| `incoming_electro_on_pyro` | `reaction_profile.overloaded.incoming_electro_on_pyro` |

## 2. 签名与元素量

| incoming_element | observed_aura_kind | 消费关系 |
| --- | --- | --- |
| `pyro` | `electro` | `1:1` |
| `electro` | `pyro` | `1:1` |

设 ICD 后后手预算为 `I`、匹配 Aura 为 `A`：

```text
consumed = min(I, A)
incoming_remaining = I - consumed
aura_remaining = A - consumed
```

无伤害元素施加也能形成超载。序列结束后的后手剩余量不自动形成持久 Aura。

## 3. Reaction Profile 与伤害

两个方向都使用 `TransformativeReactionProfile`，并冻结：

```text
damage_element = pyro
base_multiplier = 2.75
elemental_amount = 0
can_crit = false
strike_type = blunt
```

伤害使用共享剧变公式并读取目标火抗。90 级角色、`EM = 0`、零反应加成、抗性乘数 `1.0` 的 golden 值为：

```text
1446.853 * 2.75 = 3978.84575
```

共享公式、来源捕获和审计见[剧变反应伤害契约](../剧变反应伤害契约.md)。

## 4. Effect Group 与范围

每个超载 occurrence 产生一个 `ReactionEffectGroup`，其中只有一个 `GeneratedDamageImpactEffect`。它在同帧下一 settlement round 执行。

目标选择固定为：

```text
anchor = occurrence subject
geometry = circle_xz
radius = 5.0
include_anchor = true
eligibility_policy_key = reaction_target.hostile_effect
sort_policy_key = distance_xz_then_subject_ref
```

协调器冻结一次候选集合；只有 hostile 且具备 Damage capability 的目标进入超载伤害 Gate 和 Damage 计划。

## 5. Damage Gate

```text
window_frames = 30
max_damage_instances = 1
```

Gate slot 由 `gate_definition_key + trigger_source_ref + damage_target_ref + damage_kind_key` 唯一确定。

- 第 `N` 帧首次允许；`N + 29` 仍阻止；`N + 30` 重新允许。
- 不同来源、目标或伤害种类使用不同 slot。
- blocked 不修改 Gate Record/version，不创建超载 Damage 计划。
- Gate 只控制超载伤害，不撤销 occurrence、元素消费或钝击命中语义。

## 6. 钝击与碎冰

超载固定携带 `StrikeType.BLUNT`。范围内 hostile 且具备 Aura capability 的冻结目标可以形成 `reaction.shattered`：

```text
round 1 overload effect group
-> prepare Shattered occurrence
-> consume Frozen Aura / FrozenState
-> enqueue Shattered Damage Effect
round 2
-> settle Shattered physical damage
```

超载 Damage Gate blocked 时仍可碎冰；碎冰伤害使用自己的 Gate。钝击不包含击退、硬直、削韧、停滞或空间位移。

## 7. 正常空结果与失败

以下不形成普通超载：

- 后手不是火或雷；
- 没有对应的正普通雷/火 Aura；
- ICD 后预算为零；
- 同元素施加。

目标关系不适用、缺少 Damage/Aura capability 或 Damage Gate blocked 是目标级正常结果。缺 Profile、Gate Definition、Damage Profile、来源捕获或稳定引用不一致必须使当前 batch 失败。

长期覆盖两个方向的 `1:1` 消费、无伤害施加、公式值、5 米边界、稳定目标排序、`30/1` Gate、不同来源/目标分槽、事务零提交，以及 Gate blocked 时钝击仍能碎冰。

# 月结晶反应设计

> 状态：正式规范。
> 本文说明与普通结晶并列的独立水岩月结晶反应的设计语义：月笼、队伍级共享累计器、谐奏攻击流程与溢出。稳定标识、State 字段、冻结参数、事务边界与非目标见[月结晶反应契约](../../../../契约/元素反应/反应/月结晶反应契约.md)。
> 最后更新：2026-09-30。

## 1. 定位

月结晶是与普通结晶机制簇并列的独立反应，使用独立 `reaction.lunar_crystallize` Definition、Rule、Profile、月笼状态、共享累计器和月曜伤害路径，不归入 `mechanics/crystallize/` 机制目录。

月结晶在满足队伍 capability、角色触发来源和严格水岩元素签名时排他选中水结晶方向；本次交互只产生月结晶 occurrence，不同时产生普通结晶 occurrence。火、雷、冰结晶方向不受影响，保持普通结晶。没有 capability 或合法角色触发来源时，月候选不匹配，普通水结晶候选继续生效。

月结晶成立时按普通结晶的岩水消费关系消费元素量，不创建水晶片，不产生反应伤害本身；伤害来自月笼的谐奏攻击，属于反应月曜伤害。月结晶不使用普通结晶目标级成立 Gate，可以高频触发。

## 2. 领域所有权

| 领域 | 月结晶相关职责 |
| --- | --- |
| Aura | 水元素量、逐来源贡献账本与消费后值 |
| Reaction | 独立 Definition、严格水岩候选、参与者冻结、月笼 State、队伍级共享累计器、谐奏发射计划与 Effect 声明 |
| Space | 月笼 `REACTION_OBJECT` 的位置投影、生命周期与创建/销毁声明 |
| Damage | 反应月结晶复合月曜伤害的组分结算、排序加权和审计 |
| Coordination | 月笼集合生成/复用、累计器追加与消费、谐奏目标选择、冷却推进和批次提交；不实现月结晶公式 |

## 3. 候选、方向与元素消费

月结晶只接受后手岩命中正水 Aura 的严格水岩方向，候选要求队伍 capability、上游确认的角色来源集合，且当前触发来源属于该集合；冻结目标不进入候选。元素消费与普通结晶一致（先手水量按固定比例决定后手岩的消费量），不创建水晶片、不使用普通结晶成立 Gate、不产生反应伤害本身。

候选方向键、选择优先级与消费口径见[月结晶反应契约](../../../../契约/元素反应/反应/月结晶反应契约.md)第 1、2 节。

## 4. 月笼集合

Reaction 拥有队伍级月笼 State，Space 拥有位置投影；两侧通过稳定 binding ref 原子创建、替换和移除，字段与约束见[月结晶反应契约](../../../../契约/元素反应/反应/月结晶反应契约.md)第 3 节。

场上常态为三枚同步生命周期的月笼。每次月结晶 occurrence：没有月笼时销毁场上旧月笼并在触发目标附近等距生成新月笼，附近已有月笼时不生成；随后追加一条参与者记录到共享累计器。月笼是不可移动、无碰撞模型、不占角色岩造物公共上限的岩元素创造物；生成半径、索敌范围与存活窗口等冻结数值见契约第 3 节。岩造物干扰生成位置在首切片忽略，投射物阻挡属于当前 Space 模型边界。月笼超时由到期协调器原子移除 State 与 Space 实体。

## 5. 共享累计器与溢出

月结晶累计属于队伍侧机制实例，不按反应目标保存；因为下一次谐奏需要知道被消费的各次月结晶分别有哪些反应参与者，必须按 occurrence 顺序保存记录。记录字段与容量见契约第 4 节。

每次月结晶追加一条记录，超过容量时丢弃最旧记录；累计达到触发条数时尝试发射谐奏。受月笼飞行冷却或月笼销毁影响无法发射时记录继续累计（溢出）：延迟发射消费最早的记录后，剩余记录会让后续更少的月结晶就再次触发谐奏，直到溢出耗尽。

## 6. 谐奏攻击

谐奏没有独立冷却，只按累计次数触发。

目标选择：谐奏目标为当前受角色攻击的单个目标，必须同时处于三枚月笼的索敌范围内；候选按距月笼集合锚点最近选择，并列取稳定 subject ref 较小者，不要求等于触发月结晶的目标。三枚月笼必须全部未在飞行冷却且未到期，否则本次不消费记录、累计溢出。

发射与冷却：每枚月笼发射后进入投射物飞行冷却，冷却结束前该月笼不能再攻击；发射同时刷新月笼存活窗口。谐奏伤害立即结算（下一 settlement round），不模拟投射物命中延迟，投射物飞行只作为月笼冷却状态。冷却帧与存活窗口见契约第 3、5 节。

谐奏伤害：参与本次谐奏的角色取本次消费的各次月结晶参与者之并集。三枚月笼分别创建独立复合伤害请求，各组分逐月笼重新判定暴击，每枚月笼完成后独立排序并加权聚合。谐奏伤害属于反应月曜伤害，使用月曜生产公式的反应复合模式；参与者并集与伤害请求口径见[月结晶反应契约](../../../../契约/元素反应/反应/月结晶反应契约.md)第 5 节，公式、参数与权重见[伤害系统契约](../../../../契约/伤害系统契约.md)第 6 节。谐奏不消费目标元素量，不产生元素附着。

## 7. 当前边界

- 正式角色 content 的 capability 绑定仍待角色内容设计；golden case 使用临时 capability 端口。
- 月笼投射物阻挡、月笼随机选择的可回放随机协议未进入本切片（当前按距离 + 稳定 ref 确定性选择）。
- 岩造物干扰生成位置、月笼强化和其他角色专属效果属于后续 content/Space 切片。
- 月曜组分继续使用注入式暴击决策；随机选笼、随机选目标或追加攻击的可回放随机协议必须由 Damage/仿真随机基础设施统一定义，不能由月结晶机制自行引入全局随机。

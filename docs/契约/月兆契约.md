# 月兆契约

> 状态：第一版已确认。数值基线：原神 BWIKI《队伍加成》页「月兆」节
> （2026-07-02 更新，覆盖月之八版本）。
> 最后更新：2026-08-10

## 1. 等级

```text
moonsign.level.none
moonsign.level.nascent
moonsign.level.ascendant
```

| 月兆角色数量 | 等级 | 效果 |
| --- | --- | --- |
| 0 | `none` | 无 |
| 1 | `nascent`（初辉） | 全队获得初辉标记 |
| >= 2 | `ascendant`（满辉） | 全队获得满辉标记（含初辉）；非月兆角色 E/Q 触发月曜增伤 |

## 2. 非月兆角色月曜增伤

- 触发：月兆满辉，且非月兆角色施放元素战技或元素爆发。
- 时长：`1200` 帧（20 秒），覆盖式（无法叠加，后施放替换）。
- 上限：`0.36`（36%）。

元素缩放（`stat / divisor * ratio`，结果限制在 `0..0.36`）：

| 元素 | 属性 | divisor | ratio |
| --- | --- | ---: | ---: |
| 火 / 雷 / 冰 | `stat.atk.total` | `100` | `0.009` |
| 水 | `stat.hp.max` | `1000` | `0.006` |
| 岩 | `stat.def.total` | `100` | `0.01` |
| 风 / 草 | `stat.elemental_mastery` | `100` | `0.0225` |

属性在动作开始帧查询；增伤为小数倍率，注入
`LunarReactionDamageInput.reaction_bonus`。

## 3. 领域模型

```text
MoonsignLevel: none | nascent | ascendant（rank 0/1/2）
MoonsignScaling: divisor / ratio
MoonsignStatSnapshot: atk / hp_max / def_total / elemental_mastery
MoonsignBonusRecord
├── source_ref: AttributeSubjectRef
├── value: float
├── applied_frame: int
└── expires_at_frame: int（半开区间，到期帧不生效）
```

## 4. 事件载荷

| 事件 | 载荷字段 |
| --- | --- |
| `MOONSIGN_LEVEL_SET` | `level`、`moonsign_character_refs`、`established_frame` |
| `MOONSIGN_BONUS_APPLIED` | `frame`、`source_ref`、`value`、`expires_at_frame` |
| `MOONSIGN_BONUS_EXPIRED` | `frame`、`source_ref`、`value` |

## 5. 识别与装配

- 月兆角色：角色 `ContentUnit.metadata["moonsign"] == true`。
- `application/assembly/moonsign.py::build_moonsign_bundle()` 输出
  `MoonsignRuntimeBundle`（Store + Runtime）。
- 月兆等级只在组装期设置一次，二次写入报 `MoonsignStateConflictError`。

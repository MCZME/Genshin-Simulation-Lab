# 月感电反应设计

> 状态：正式规范。
> 本文说明与普通感电并列的独立月感电反应的设计语义：排他选中、领域所有权与雷暴云周期攻击流程。稳定标识、State 字段、冻结参数、事务边界与非目标见[月感电反应契约](../../../../契约/元素反应/反应/月感电反应契约.md)。
> 最后更新：2026-09-30。

## 1. 定位

月感电是与普通感电机制簇并列的独立反应，使用独立 `reaction.lunar_electro_charged` Definition、Rule、Profile、雷暴云状态、周期攻击根和月曜伤害路径，不归入 `mechanics/electro_charged/` 机制目录。

月感电在满足队伍 capability、角色触发来源和严格水雷元素签名时排他选中；本次交互只产生月感电 occurrence，不同时产生普通感电 occurrence。没有 capability 或合法角色触发来源时，月候选不匹配，普通候选继续生效。

月感电 occurrence 本身不产生伤害，也不消耗水、雷元素量；它只创建或刷新雷暴云，并让本次后手元素以普通损耗形成持久 Aura，使水雷保持共存。伤害来自雷暴云的独立周期攻击，属于反应月曜伤害。

## 2. 领域所有权

| 领域 | 月感电相关职责 |
| --- | --- |
| Aura | 水、雷元素量、逐来源贡献账本、攻击时精确消费与后值 |
| Reaction | 独立 Definition、严格水雷候选、参与者冻结、雷暴云 State、攻击计划和逐目标 Damage Gate |
| Space | 雷暴云 `REACTION_OBJECT` 的位置投影、生命周期与创建/销毁声明 |
| Damage | 反应月感电复合月曜伤害的组分结算、排序加权和审计 |
| Coordination | 帧规范化物化攻击根、逐目标检查水雷 Aura、冻结参与者、Gate/消费/伤害的批次提交；不实现月感电公式 |

## 3. 候选、方向与元素消费

月感电只接受严格水雷两个方向，候选要求队伍 capability、上游确认的角色来源集合，且当前触发来源属于该集合；不接受其他元素共存签名。occurrence 不消费任何元素量，后手元素以标准损耗形成持久 Aura，水雷继续各自自然衰减。

稳定方向键、候选条件、选择优先级与消费口径见[月感电反应契约](../../../../契约/元素反应/反应/月感电反应契约.md)第 1、2 节。

## 4. 雷暴云生命周期

Reaction 拥有队伍级雷暴云 State，Space 拥有位置投影；两侧通过稳定 binding ref 原子创建、刷新和移除，字段与约束见[月感电反应契约](../../../../契约/元素反应/反应/月感电反应契约.md)第 3 节。

触发月感电只影响雷暴云的生成与维持：附近没有雷暴云时在目标位置创建一朵，已有时刷新存在时间并保留实例身份、触发来源和攻击游标。同一队伍、同一时刻附近存在多朵过近雷暴云时，保留存在时间最长的一朵，其余云的 State 与 Space 实体原子移除。生成锚点、云间排斥半径与攻击半径在本切片使用同一个确定性最小可行值，精确数值仍待人工确认。

雷暴云到期由到期协调器原子移除 State 与 Space 实体。当前最小可行边界：刷新只延展 State 到期时间，不更新 Space 实体生命周期投影；到期移除以 State 为准。

## 5. 周期攻击

帧规范化把本帧 due 的雷暴云攻击冻结为 scheduled root 工作并推进攻击游标；scheduled root adapter 把根工作投影为下一 settlement round 的范围攻击 Effect group。

每个合法敌对目标独立准备攻击：先校验其水、雷 Aura 与角色贡献，通过逐目标 Damage Gate 后，从消费前的贡献账本冻结角色参与者并精确消费水雷元素量，最后以反应复合月曜输入进入统一 Damage Impact。攻击范围、Gate 窗口、消费量、参与者冻结与去重口径见[月感电反应契约](../../../../契约/元素反应/反应/月感电反应契约.md)第 4 节。

Gate 阻止时该目标不消费、不受伤。雷暴云攻击不是角色元素施加，不额外加入创建云的触发方。

## 6. 反应月曜伤害

雷暴云攻击伤害使用月曜生产公式的反应复合模式：每个角色组分独立完成等级基数、精通、暴击、擢升和抗性结算，再按完整组分伤害排序并加权聚合。公式、参数与权重见[伤害系统契约](../../../../契约/伤害系统契约.md)第 6 节。

伤害分类使用独立的月感电 Damage Profile 与 Damage kind，与普通感电互不混淆。

## 7. 当前边界

- 正式角色 content 的 capability 绑定仍待角色内容设计；golden case 使用临时 capability 端口。
- 角色月感电伤害入口（`CHARACTER_DIRECT`）待角色内容设计，本切片只实现反应月感电（雷暴云攻击）。
- 雷暴云移动、阻挡、复杂碰撞和其他需要完整空间几何的规则不由当前 `Space` 最小模型推测；岩造物干扰和角色专属雷暴云强化属于后续 content/Space 切片。
- 反应月曜伤害继续使用注入式暴击决策；可回放随机输入的统一协议尚未冻结，不能在本机制中自行引入全局随机源。

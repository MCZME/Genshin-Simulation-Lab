# 节点与区域契约

> 状态：正式规范。
> 本文定义节点、区域、端口、数据语言、连接规则与节点参数契约。
> 最后更新：2026-09-02。

## 1. 定位

- 节点类型、区域归属、端口模型、数据语言、参数 schema 与节点级校验是稳定契约。
- 语义注册表由 `frontend/src/workflow/registry.ts` 持有，前端拥有图语义。
- 后端不持有节点注册表；分析查询计划只接收已展开的节点参数。
- 节点 `kind` 冻结：只追加、不改名、不复用；删除节点时明确走契约修订。

## 2. 区域模型

### 2.1 配置区域

- `region.kind = configuration`
- 无独立输入端口。
- 边界输出 `out` 同时作为区域内节点链的汇入目标与连接模拟节点的输出源。
- 区域输出经编译形成 `SimulationInput` 文档或变体成员。
- 设计说明见[配置区域设计](../../架构/UI/配置区域设计.md)。

### 2.2 分析区域

- `region.kind = analysis`
- 有边界输入 `in`，语言为 `session_group`。
- 边界输入是区域内数据的唯一输入源，允许多个画布级源节点合并。
- 分析区域不直接提供边界输出；区域内结果通过视图和单项详情节点呈现。

### 2.3 画布级节点

- `region: null`，不属于配置区域或分析区域。
- 包括 `simulation` 与 `data_provider`。

## 3. NodeKindSpec

每个节点类型至少声明：

| 字段 | 含义 |
| --- | --- |
| `kind` | 稳定 key |
| `display_name` | 用户可识别名称 |
| `region` | `configuration` / `analysis` / `null` |
| 端口模型 | 输入输出端口、数据语言、基数、连接数约束 |
| 片段形状 | 默认目标路径与参数形状 |
| 参数 schema | 类型化节点参数 |
| 默认参数 | 创建节点时写入的默认值 |
| 节点级校验 | 该类型特有校验规则 |

## 4. 数据语言

### 4.1 session_group

- 会话 ID 的有序去重列表。
- 来源：分析区域边界输入、`data_provider`、`simulation`。
- 只能进取数节点 `fetch`。

### 4.2 table

- 列名 + 类型的一组行。
- 来源：`fetch`、数据处理节点、饼图/柱状图 `selection` 输出的分组行集。
- 可进视图数据输入、下游算子输入和 `single` 输入。
- 饼图/柱状图 `selection` 的行集表是点击派生的客户端表，不进入查询计划；
  当前登记为 selection 输出值，图内消费规则另行登记。

### 4.3 展示配置

- `table_config` / `pie_config` / `bar_config` 三种配置语言。
- 只进对应视图节点的配置输入。

### 4.4 item

- 一个数据对象，表示一行、一个区间或一个曲线点。
- 来源：表格视图 `selection` 输出、`single` 节点。
- 只能进单项详情节点。

## 6. 端口与连接规则

- 端口有稳定 `port_id`；节点默认支持多输入多输出。
- 同一输入端口允许多条入线，多条上游按端口顺序先连先应用。
- `item` 输入端口只接受 `item`，不接受 `table`。
- `member_table` 的 `selection` 输出端口语言为 `item`；`pie` / `bar` 的 `selection` 输出端口语言为 `table`（点击扇区/柱输出该组命中的输入行集）。均为瞬态选择输出，不改变视图的整组渲染。
- `single` 是 `table -> item` 的唯一显式转换入口；单项详情节点不能自行接收整表。
- 基数：单值输出 / 组输出；组输出触发下游展开。
- 成员投影端口：`out:<item_id>`，绑定稳定 `item_id`，不同成员分支互斥。
- 多路独立输出重新汇入时不得静默恢复成组、拼接或叉乘。

## 7. 参数与默认值

- 参数 schema 类型：`string` / `integer` / `number` / `boolean` / `text` / `asset_ref` / `list` / `range` / `object` / `json_fragment`。
- 前端创建节点时写入默认参数；编译阶段沿用同一默认值。
- 固定路径节点不提供路径编辑；只有 `enum` / `range` 在表单中配置目标路径。
- 展示配置参数和单项详情节点参数以[分析区域设计](../../架构/UI/分析区域设计.md)和[分析系统契约](../分析系统契约.md)为真值源。

## 8. 演进规则

- 节点 `kind`、端口 `id`、数据语言和参数结构冻结，只增不改。
- 开发阶段不维护旧节点兼容；移除节点时同步更新注册表、工作流校验和相关文档。
- 编辑器展示元数据不进入本契约，见[前端工程规范](../../工程/前端工程规范.md)。
